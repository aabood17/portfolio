## What I built

- A **full-stack social platform** with secure authentication, real-time messaging and notifications.
- **Backend** in Java and Spring Boot, secured with JWT, OAuth2 and SSL.
- **Frontend** in React and TypeScript, based on a UI I designed in Figma.

## Architecture

The application started as a single service and was then **refactored into a microservices architecture**, splitting responsibilities into independent services that can be developed and deployed separately.
