## What we built

- A **full-stack social platform** with secure authentication, real-time messaging and notifications.
- **Backend** in Java and Spring Boot, secured with JWT, OAuth2 and SSL.
- **Frontend** in React and TypeScript, based on a UI we designed in Figma.

## Architecture

The application started as a single service and was then **refactored into a microservices architecture** as part of a university course on microservices, splitting responsibilities into independent services that can be developed and deployed separately.

## How we worked

We were a team of three and built the project together, working on every part as a group. The code was pushed to the course repository from one teammate's machine, so the commit history shows a single author.
